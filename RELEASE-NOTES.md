# LockLens v1.0

Portable file and folder usage finder for **Windows 10/11 x64**.

Download **LockLens.zip**, extract it, and run **LockLens.exe**. No installation required.

- Find processes using a file, folder, or files inside it.
- Inspect process IDs, program locations, and related paths.
- Copy reports, open Task Manager, or restart as administrator.
- Close a process with confirmation; force-ending requires another confirmation.
- Choose **English / 简体中文** in **More → Language / 语言**. The choice is remembered.
- Includes the corrected portable taskbar icon.

Application and documentation versions are unified as **1.0**. This refresh replaces the earlier Chinese-only package under the same tag.

Verified: real file locks, folder handles, Unicode paths, cancellation, process identity, taskbar icon metadata, live language switching, reports, and saved language preferences.

All checks run locally. Save your work before ending a process. The executable is unsigned. Windows dialogs and OS errors use the system language.

## LockLens v1.0

A portable Windows tool for finding programs that are using a file or folder.

### Download and run

Download **占用查找器-图标修复版.zip**, extract it, and double-click **占用查找器.exe**. No installation is required.

Supports **64-bit Windows 10 and Windows 11**. The current interface is in **Simplified Chinese**.

### Features

- Find processes using a selected file or folder.
- Inspect process IDs, executable locations, and related paths.
- Open program locations, copy reports, and access Task Manager.
- Restart as administrator when additional access is needed.
- Close a process with confirmation, with a separate confirmation before forcing it to stop.

### This version

- Simplified the main interface.
- Fixed the portable application's taskbar icon association.
- Verified real file locks, directory handles, Unicode paths, cancellation, process identity checks, and taskbar icon metadata.

All scans run locally. Save your work before closing or force-ending a process.

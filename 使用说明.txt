LockLens 1.0
============

使用方法
1. 双击 LockLens.exe。支持 Windows 10/11 64 位，无需安装。
2. 拖入文件或文件夹，也可粘贴完整路径。
3. 点击“查找”，选中结果查看程序位置与相关路径。
4. 先保存工作并正常关闭对应程序，再尝试删除、重命名或移动。

语言切换
更多 → Language / 语言 → 简体中文 / English。
立即生效，并保存在 %LOCALAPPDATA%\LockLens\language.txt。
首次启动：中文 Windows 默认简体中文，其他系统默认英文。
扫描和结束进程期间暂不可切换；系统对话框和 OS 错误消息使用系统语言。

其他操作与限制
“更多”提供完整报告、任务管理器和管理员重试。
结束进程先尝试正常关闭；强制结束需再次确认，可能丢失未保存内容或中断服务。
“系统报告占用”来自 Windows；“发现打开句柄”不一定阻止删除。
未发现结果不能保证一定可以删除，也可能受权限、驱动或短暂占用影响。
受保护系统进程可能无法检查；网络共享请在共享所在电脑检查。
文件夹系统核实最多遍历 20,000 个文件或 10 秒，跳过无权限目录和内部链接。
句柄扫描独立检查可访问进程，每个工作进程限时 4.5 秒。

隐私
不联网、不上传文件、不删除目标、不卸载软件、不安装后台服务。
仅保存语言偏好。删除程序文件及语言偏好目录即可完整移除。
程序未进行商业代码签名。

English
-------
Run LockLens.exe, select/drop a file or folder, and click Search.
Select a result to view process IDs, program locations, and related paths.
Use More → Language / 语言 to choose English or Simplified Chinese.
The preference is saved in %LOCALAPPDATA%\LockLens\language.txt.
Save your work before closing a program; forcing a process to stop requires
another confirmation and may lose unsaved data or interrupt services.
All checks run locally. Protected processes may be inaccessible. No results
do not guarantee deletion is possible; see the full report for scan limits.
Requires Windows 10/11 x64 and .NET Framework 4.5+ (included with Windows 10/11).
The executable is unsigned. OS dialogs and errors use the system language.

Download: https://github.com/lamiqsnp-crypto/LockLens/releases/latest
